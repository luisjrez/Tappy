# Triage labels

| Rol canónico | Etiqueta GitHub | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Pendiente de evaluación |
| needs-info | needs-info | Falta información para definir o ejecutar |
| ready-for-agent | ready-for-agent | Especificado; respetar bloqueos y requisitos externos |
| ready-for-human | ready-for-human | Requiere ejecución humana |
| wontfix | wontfix | No se realizará |

Etiquetas descriptivas: backend, story, task, tdd, external-dependency, scope:additional. Una historia agrupa; no se ejecuta como una subtarea gigante. Una dependencia abierta no se elimina porque el ticket tenga ready-for-agent.
